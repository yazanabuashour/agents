---
name: notes
description: Use whenever durable knowledge, notes, or information need to be read or written.
---

- Search before writing; update the canonical note instead of creating duplicates.
- Save useful context within the authorized scope. Keep task state in task systems.
- Before drafting or materially rewriting prose, read
  [technical-writing](../technical-writing/SKILL.md) and apply its prose guidance,
  not documentation-only rules. Skip this for reads and verbatim captures.
- Preserve existing IDs, links, source evidence, and meaningful dates.
- Run local checks required by the directory's instructions. Verify the saved
  content and report its local path; a local save is not publication.
- If the directory is unavailable, report the blocker and any unsaved context.
