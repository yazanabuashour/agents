---
name: notes
description: Use whenever durable knowledge, notes, or information need to be read or written.
---

Use `~/notes`, or `https://github.com/yazanabuashour/Notes.git` through existing
authentication. Read the repository's `AGENTS.md` for organization, checks, and
submission instructions.

- Search existing notes before creating one; update the canonical note rather
  than a near-duplicate.
- Save useful context as it emerges within the authorized scope, not just in
  the conversation. Task systems own task state.
- Before drafting or materially rewriting prose, read
  [technical-writing](../technical-writing/SKILL.md). Skip this for reads and
  verbatim captures; preserve source text, evidence, and meaningful dates.
- Preserve existing IDs and links. Return a verified note link when available;
  never invent one.
- Remote submission requires explicit user authorization, not just access.
- Verify what was saved and where. Do not imply submission, integration, or
  publication from a local save.
- If access is unavailable, report the blocker and any unsaved context. Do not
  change authentication or claim that the information was written down.
