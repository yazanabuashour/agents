# Security policy

Security fixes target `main`; older commits receive no backports.

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/yazanabuashour/agents/security/advisories/new).
Include the affected commit, agent and operating-system versions, reproduction
steps, and impact. Redact private prompts, credentials, account data, and unnecessary
host paths. If private reporting is unavailable, contact the maintainer through
the repository profile to arrange a private channel before sending exploit details.

Instructions are guidance, not an authorization boundary or sandbox. Workflow
helpers run with the invoking account's permissions; agents and applications retain
ownership of credentials and trust. Do not submit undisclosed vulnerabilities in
public issues.
