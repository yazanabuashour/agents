# Contribute to agents

Keep changes focused on reusable instructions, shared skills, and their workflow
helpers. Review the [development checks](docs/development.md) before changing
installation or loading behavior. Preserve skill licenses and attribution.

Describe the user-visible outcome, checks run, unavailable gates, and any changed
runtime dependencies or discovery behavior. Keep personal settings, private
prompts, transcripts, credentials, and generated state outside the repository.

Do not install into a live profile, change accounts, or publish as part of a
contribution. Report vulnerabilities through [SECURITY.md](SECURITY.md), not public
issues.
